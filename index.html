Workflow Guide

Recommended order for the main university operations.

ApplicationsDocument Review & Offer Letter -> Final Approval

Review documents, request corrections if needed, and upload the offer letter in the first step. Final Approval starts once the applicant submits final documents.

ProgrammesDraft -> Pending KPT Approval -> Approved -> Live

Drafts can be edited or deleted. KPT-requested changes must be corrected and resubmitted. Approved programmes can go live.

ProgrammesDraft -> Pending KPT Approval -> Live

KPT controls approval and launch. Universities can edit drafts, respond to requested changes, and archive live programmes while retaining historical applicant data.

UsersSuper Admin controls access

University Admin and Admissions Officer can work on operational areas, but cannot add users, edit roles, deactivate accounts, or view Reports.
